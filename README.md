# Billing Management System

A full-stack Billing Management System designed to streamline billing operations, product management, customer handling, and order processing through a modern web-based application.

## 🚀 Features

- User authentication and authorization using JWT
- Role-based user management
- Category and item management
- Customer information management
- Shopping cart and billing functionality
- Order creation and order history
- Invoice and receipt generation
- Dashboard with billing-related insights
- Product image upload functionality

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- Hibernate

### Database
- MySQL
